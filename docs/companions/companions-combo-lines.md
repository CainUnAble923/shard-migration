# Companion personality x class flavor (draft, 2026-10-02)

Companion to `companions-squire-evo-research.md`. Chase asked (12:44) for flavored text for every
possible personality and class combination ("a ditzy necromancer would be hilarious").

- **Scope:** every allowed personality x **branch** pairing from the personality to class map: 7 commons
  x 4 branches, Gloomy x 11 (all paths since 12:45, incl. Penitent), Isekai'd x 11 (incl. Otherworlder)
  = **50 combinations**.
- **Each has:** an **epithet** (shown in the lore window, for example "Pip the Cheerful Gravedigger") and a
  **signature line** (spoken on choosing the branch, and in the idle pool afterward).
- Before the branch (loops 0 to 2) a companion uses its personality's own lines plus its path title.
  Path-level combo lines are a possible later pass.
- All original, PG, ASCII only. Gendered words (sir, mister, lord) get a female variant in the speech
  table; epithets here are written to fit both where possible.
- If the personality to class map changes, combinations here change with it.
