# P574: unanswered questions for Chase, round 2

October 24, 2026. The list contains 116 distinct decision rows. This supplements [P532](cc-P532-open-questions-for-chase.md). Recommendations are proposals, not Chase's answers or permission to implement, publish, deploy, or change accounts. No answer is needed to finish this collection.

Read the sections in order: focused repair decisions first, then shared progression and safe housing specifications, then individual feature details and optional follow-ups. **Fix scope** blocks issuing the named policy-dependent part of a repair draft, not its independent safeguards. **Build** blocks the corresponding later implementation specification. **Release** blocks enabling or advertising a proposed feature. **Future** and **No** leave current behavior available. These consequences come from the cited notes, not a new runtime inspection.

Each source names the note and exact line in this checkout. A P532 reference means this is a narrower new decision under that earlier topic; unchanged questions are referred back to P532 in the reconciliation table. Shared questions appear once. Source numbers are unmeasured defaults unless the source explicitly records an accepted decision. The [work record](cc-P574-questions-for-chase-round-2.md) explains coverage, answer checks, and limits.
