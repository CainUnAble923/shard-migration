Use a disposable test world running this merged snapshot or a later build that contains it. For the tutorial, turn on `testCenter.enable` and `tutorial.enabled` in that fixture and use P276's matching server and client farm map patch. For dragon and hall appearance, use the matching updated player package. Record the actual build, package, character, result, and evidence when executing a plan. Use an ordinary Player-access Human unless an item specifies another race or an Admin. Admin prepares fixtures and observes state; player actions finish lessons and earn rewards. Use separate fresh accounts for independent graduation, farm-pet, and skip cases because tutorial progress belongs to the account. Never reset a real player's record. Restart, date, non-test-mode, world-generation, and deletion comparisons belong to isolated scratch saves. This task authorizes writing plans only, not executing those future operations.
