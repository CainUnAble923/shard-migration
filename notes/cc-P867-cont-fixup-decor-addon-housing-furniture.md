## Deviations and decisions for Chase

- **Medium and grand grey fireplaces are 21 tall.** That is one more than a classic storey. So they are refused
  under an upper floor 20 over theirs: a two-story house's ground floor, or a custom house's lower floor. Elsewhere
  they place fine. The fix would be to drop the top piece by one Z in those four files. That changes Diesel's
  design, so I left it for you.
- **Shots are staff-placed, not owner-placed.** The guide wants every piece shot from the default camera inside a
  room. No owned house on the proof shard gave both a clear camera and a free wall for every piece:
  - New Haven has no flat clear plot for a house;
  - on Felucca the land showed through floors;
  - the two-story house's upper storey covered the room.

  So the shots stand each piece in a real town building by staff, and the deed path is run 4's three owner
  placements.
- **The large and grand east fireplaces in a classic house.** Within the plain classic houses I looked at, they had
  no spot: every west wall long enough has a window or a door within a tile. They do fit town buildings and custom
  houses, as the shots show.
- **One command was refused in the unattended run.** I wanted
  `rm -rf notes/cc-P867-review/shots/*` plus re-rendering, to empty the shots folder between runs. It was denied, so
  I copied each run's logs aside instead (`notes/cc-P867-tools/run1`-`run5`), and the next run overwrote the same
  file names. The shots folder holds run 6's files only, plus the frame grabs (`frame-*.jpg`) TazUO writes each
  run.
- **Leftover tools.** `plan867.py`, `render867.py`, `kit/Walk867.py` and `placed-rows.txt` are the house runs'
  tools (runs 2-5), kept for the record. The final run is `kit/Walk867Town.py` with `town867.py` and
  `townrender867.py`.
