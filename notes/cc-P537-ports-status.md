# ServUO ports: status as of October 24, 2026

One list of the ports named in the feature queue, the port-list notes, the earlier CC/S port notes, and the CODE-INTAKE assessments. Batch rows link to their item and creature file lists; dependencies carried with a batch belong to that row. Deferred families and assessed downloads are included so that an assessment cannot be mistaken for a completed port. Work record: [cc-P537-ports-status-list.md](cc-P537-ports-status-list.md).

ModernUO remains the shard engine. This is a content inventory, not an engine migration plan. Work-copy HEADs are code `491bb490b1f343bc99bac1f7207fbb1a847d3535` and notes `0e6ee6e922c2dea91e91554a0b0fe4bb704f6bde`. During this task local main advanced to code `82ba93fdd3e047646cdf63cb4f468b9a30b90270` and notes `7bad9b4602b82ee478cc4fc8430882c02495fa01`. Its P427 delta was read directly with git show/diff; branches were not switched. "Merged" means present in that audited local main, including work incorporated by a later fix-up. It does not mean deployed. No running service was inspected.

"Route exists" means testers have an implemented player path after the appropriate build and placement. "Staff only" means a staff-spawned demonstration, not a naturally accessible encounter. "Unverified" means the notes do not establish a client pass or current placement. Historical passes remain dated, especially where later code changed. The [play-test records](../testing/play-tests.json) show the newer dungeon, fishing, crafting and map groups still open. P119/P121 have some recorded passes, and P122 has player checks recorded on October 18.

The original [port list](port-list-2026-10-13.md) and [machine list](../tools/port-list.json) count filename stems, which can match unrelated files or miss renamed equivalents. Their completion percentages are not used here. Review findings below are source-review evidence, not newly reproduced gameplay failures.
